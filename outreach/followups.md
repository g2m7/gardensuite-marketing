# GardenSuite WhatsApp Follow-Up Sequences

This document provides structured follow-up sequences for prospects who did not reply to the first message.

---

## 1. Cadence and Operating Rules

### Recommended Timing
Tea estate owners and directors have active morning field rounds (kamjari) and factory visits.
- **First Touch**: Day 0 (Tuesday to Thursday preferred, 10:30 AM to 4:30 PM IST).
- **Follow-up 1 (New Value / Angle)**: Day 3 or Day 4.
- **Follow-up 2 (Visual / Workflow Proof)**: Day 7 or Day 8.
- **Follow-up 3 (Soft Breakup / Respectful Exit)**: Day 14.

### Core Rules
1. **Never say "Just following up" or "Checking if you saw my previous message."** Each message must provide fresh context or address a different angle of the workflow.
2. **Maximum 3 follow-ups**: If no response after 3 follow-ups, stop. Mark lead as `No Response` in the tracker.
3. **Immediate Exit on Objection or Opt-Out**: Any explicit "No", "Not interested", "Stop", or negative response must result in an immediate polite sign-off and suppression. Never argue or send another follow-up.
4. **Length**: 25 to 55 words. Even shorter than the first touch.

## 3. What to Do When a Prospect Reads (Blue Ticks) but Does Not Reply

If a message is marked read (double blue ticks) but receives no reply after 48 hours:
- **Do not send an aggressive "Saw you read this" message.** That feels intrusive and damages credibility.
- Wait for the regular Day 3 or Day 4 cadence window.
- Send the planned Follow-up 1, which adds an objective technical detail (like offline capability or video clip).
- If still no reply after Follow-up 1, proceed normally to Follow-up 2 and Follow-up 3.

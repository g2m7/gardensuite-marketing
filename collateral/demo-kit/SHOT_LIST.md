## Recording rules

- Demo estate data only. No real worker names, faces or wages without written permission.
- Use the real Bluetooth scale for every weighing shot. Turn off any fake scale or test mode in the app. The status line must read "Scale connected" with no "Fake" label.
- Phone screenshots: keep the same phone and size as the current set (412 x 915 at 1x, or any 9:20 screen), so new ones drop straight into the deck.
- Record at 1080p or better.
- Turn on Do Not Disturb so no notifications appear.
- Keep the status bar clean and the battery above 50 percent.
- Save originals in `assets/source/videos/` (for video) or `assets/source/product-screenshots/` (for photos and screenshots).
- Use descriptive file names like `weighing_handson_2026-10.mp4`.

03 / 12 - Sync Settings
Step 2 of 9 - Mobile App

Sync Data to Phone

Download workers, divisions, and active work codes from the cloud database to the mobile device. This syncs the offline app database.

1
Open App Settings Tap the gear icon on the main app dashboard.
2
Verify Server URL Ensure the correct garden server domain is set (provided by Sarbani Associates).
3
Tap "Sync Now" Downloads the latest employee profiles and settings to the phone's offline database.

05 / 12 - App Settings
Step 4 of 9 - Mobile App

App Configuration

Biometric thresholds, active camera selection, and database import/export options are pre-configured. Do not adjust these values without support.

1
Recognition Threshold Set to locked brand-safe values (0.75-0.80) to optimize recognition accuracy and speed.
2
Camera Selection Toggle between front and rear cameras depending on your weighing setup.
!
Biometric Data Backup Backup face databases offline. Do not change default database locations.

08 / 12 - Sync Attendance
Step 7 of 9 - Mobile App

Sync Attendance Data

Attendance data is automatically synced to the cloud. You only need to trigger a manual sync if records are late or connection was lost.

1
Auto Sync
2
1
Automatic Upload The app automatically syncs all punches and weights to the Dashboard when internet is active.
2
Sync Only If Late If data is delayed or connection was weak, open Settings and tap "Sync Now" to force a manual sync.

Verify Synced Attendance

## Questions and deterministic results

Answers for every question: Yes / No / Not sure. A No produces a reporting check; Not sure produces a verification question. A Yes produces no adverse finding.

| ID | Question | If No | If Not sure |
| --- | --- | --- | --- |
| Q1 | Can you see worker-wise attendance behind the daily total? | Ask for worker-wise hazira supporting the total for one selected day. | Ask where the worker-wise record behind the total can be viewed. |
| Q2 | Can you see how each worker's identity was checked? | Ask how identity is checked and how attendance recorded by a fallback method is marked. | Ask the office to explain the identity-check and fallback process. |
| Q3 | Can you see attendance by section and work? | Ask for a section/work breakdown alongside the daily total. | Ask whether the existing report already includes a section/work breakdown. |
| Q4 | Can you see attendance corrections, their reasons and who approved them? | Ask for a correction summary showing the reason and approving person. | Ask where corrections and approvals are recorded and who can review them. |
| Q5 | Can you tell whether the day's records are complete or some are still waiting to arrive? | Ask for a complete/pending status and the date/time of the latest received records. | Ask how the office confirms that all expected field records have arrived. |

Show each applicable item, grouped into Things to check in your next report and Questions to confirm with the office. Display up to two items first with a clear expand option if mobile space requires it. Do not hide the remaining result behind contact capture.

All Yes: Your answers suggest these five checks are already available. You can use the report format below to review whether they are easy to find each day. This self-check does not verify the accuracy of your estate's records.

Other outcomes: Based on your answers, these are details to check in your next daily attendance report. A missing detail is not evidence of wrongdoing.

## Example result

You said you cannot see attendance corrections and are not sure whether every field record has arrived.

Ask for a correction summary and a complete/pending status with the daily total. This can help you distinguish a final report from one still waiting for information.

## One-page owner report format

Title: Daily hazira review for the owner

| Item | Record / question |
| --- | --- |
| Estate and reporting date | Estate: ____ Date: ____ |
| Latest information received | Date/time: ____ |
| Completeness | Complete / Pending / Not confirmed |
| Expected versus received field records | Expected: ____ Received: ____ Explanation: ____ |
| Attendance total | Workers shown present: ____ Source: ____ |
| Section and work breakdown | Attach or link the supporting breakdown: ____ |
| Worker-wise detail | Where it can be reviewed: ____ |
| Identity checks / permitted fallback | Method and exception reference: ____ |
| Corrections | Count/reference: ____ Reasons recorded: Yes / No |
| Office review | Reviewed by: ____ Date/time: ____ |
| Owner follow-up | Item to clarify: ____ Responsible person: ____ |

Using the format: Choose one reporting day. Ask the office to complete what is available and mark the rest not available or not confirmed. Confirm the meaning of totals before comparing them. A missing record is not zero attendance. Review one unresolved item rather than treating every blank as a loss.

This is a suggested manual report format. It does not claim that every field already exists in the standalone product. Demonstration and quotation must specify which are currently supplied automatically.

Footer: Prepared by GardenSuite, Sarbani Associates. Many estates keep software details private. Use this format within your own estate's review process.

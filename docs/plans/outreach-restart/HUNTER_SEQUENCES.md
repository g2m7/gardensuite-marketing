# Hunter Sequences Alternative

**Status:** Not selected for the current pilot

Hunter was considered because its free plan supports cold-email sequences. It was rejected for this pilot because the free plan connects only Gmail or Outlook mailboxes. Custom SMTP/IMAP requires a paid Hunter plan.

The owner requires sending from an existing domain mailbox and does not want Google Workspace.

Use [`SNOV_IO_CAMPAIGNS.md`](SNOV_IO_CAMPAIGNS.md) for the current plan.

Official reference: [Hunter plans and mailbox connections](https://help.hunter.io/en/articles/11131690-pricing-plans-and-feature-faqs)
